# HQ Meistertrainer

Lern-App für die Prüfung **Geprüfter Industriemeister Metall – Handlungsspezifische Qualifikationen**.

- 62 Situationsaufgaben mit Lösungshinweisen (Technik, Organisation, Führung & Personal)
- 20 Rechenaufgaben-Typen mit immer neuen Zahlen und Lösungsweg
- Antworten tippen, mit dem Stift schreiben oder auf Papier fotografieren
- Lernkartei mit Wiederholung, Prüfungssimulation mit Note nach IHK-Schlüssel
- läuft komplett offline; optionale KI-Korrektur mit eigenem Anthropic-API-Schlüssel

**Download:** neueste APK unter *Releases*. Web-Version über GitHub Pages.

Alle Aufgaben sind eigene Formulierungen nach den Prüfungsthemen, keine Original-IHK-Aufgaben.
